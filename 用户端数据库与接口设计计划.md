# 学生笔记共享平台 - 系统架构设计文档

## 一、技术栈选择

### 1.1 后端技术栈
- **框架**: Spring Boot 3.2.x + Spring Security 6.x
- **数据库**: MySQL 8.0+ (关系型数据库，支持复杂查询和事务)
- **ORM**: MyBatis-Plus 3.5.x (简化CRUD操作，支持代码生成)
- **缓存**: Redis 7.x (用户会话、登录失败计数、热点数据缓存)
- **搜索**: (可选) Elasticsearch 8.x (如果搜索功能需要更强大的全文检索)
- **工具库**:
  - Hutool 5.x (Java工具类库)
  - Jackson (JSON序列化)
  - BCrypt (密码加密)
  - Apache Commons Lang3 (字符串处理)
  - Spring Validation (参数校验)

### 1.2 前端技术栈
- **框架**: Vue 3.x + TypeScript
- **UI组件库**: Element Plus / Ant Design Vue
- **状态管理**: Pinia
- **路由**: Vue Router 4.x
- **HTTP客户端**: Axios
- **构建工具**: Vite

### 1.3 基础设施
- **容器化**: Docker + Docker Compose
- **版本控制**: Git
- **CI/CD**: GitHub Actions / GitLab CI
- **监控**: (可选) Prometheus + Grafana
- **日志**: Logback + ELK Stack

## 三、数据库设计

### 3.1 数据库表结构

#### 3.1.1 用户表 (t_user)
```sql
CREATE TABLE `t_user` (
  `id` BIGINT NOT NULL AUTO_INCREMENT COMMENT '用户ID',
  `username` VARCHAR(50) NOT NULL COMMENT '用户名(唯一)',
  `password` VARCHAR(255) NOT NULL COMMENT '密码(BCrypt加密)',
  `email` VARCHAR(100) NOT NULL COMMENT '邮箱',
  `phone` VARCHAR(20) DEFAULT NULL COMMENT '手机号',
  `avatar` VARCHAR(255) DEFAULT NULL COMMENT '头像URL',
  `status` TINYINT NOT NULL DEFAULT 1 COMMENT '状态: 1-正常, 0-禁用, 2-锁定',
  `last_active_at` DATETIME DEFAULT NULL COMMENT '最后活跃时间(用于排序)',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_username` (`username`),
  UNIQUE KEY `uk_email` (`email`),
  KEY `idx_last_active_at` (`last_active_at`),
  KEY `idx_status` (`status`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='用户表';
```

#### 3.1.2 总链接表 (t_main_link)
```sql
CREATE TABLE `t_main_link` (
  `id` BIGINT NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `user_id` BIGINT NOT NULL COMMENT '用户ID',
  `main_url` VARCHAR(500) NOT NULL COMMENT '总链接URL',
  `view_count` BIGINT NOT NULL DEFAULT 0 COMMENT '浏览次数',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_user_id` (`user_id`),
  KEY `idx_updated_at` (`updated_at`),
  CONSTRAINT `fk_main_link_user` FOREIGN KEY (`user_id`) REFERENCES `t_user` (`id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='总链接表';
```

#### 3.1.3 笔记表 (t_note_item)
```sql
CREATE TABLE `t_note_item` (
  `id` BIGINT NOT NULL AUTO_INCREMENT COMMENT '笔记ID',
  `user_id` BIGINT NOT NULL COMMENT '用户ID',
  `title` VARCHAR(100) NOT NULL COMMENT '笔记名称',
  `note_type` TINYINT NOT NULL DEFAULT 1 COMMENT '笔记类型: 1-链接笔记, 2-创作笔记(Markdown)',
  `location_or_url` VARCHAR(500) DEFAULT NULL COMMENT '位置或链接',
  `content` MEDIUMTEXT DEFAULT NULL COMMENT '笔记正文内容 (Markdown格式)',
  `summary` VARCHAR(500) DEFAULT NULL COMMENT '笔记摘要',
  `cover_image` VARCHAR(255) DEFAULT NULL COMMENT '封面图URL',
  `view_count` BIGINT NOT NULL DEFAULT 0 COMMENT '浏览次数',
  `is_deleted` TINYINT NOT NULL DEFAULT 0 COMMENT '是否删除: 1-已删除, 0-未删除',
  `is_pinned` TINYINT NOT NULL DEFAULT 0 COMMENT '是否置顶: 1-已置顶, 0-未置顶',
  `deleted_at` DATETIME DEFAULT NULL COMMENT '删除时间',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`id`),
  KEY `idx_user_id_updated_at` (`user_id`, `updated_at`),
  KEY `idx_user_id` (`user_id`),
  KEY `idx_note_type` (`note_type`),
  KEY `idx_updated_at` (`updated_at`),
  KEY `idx_is_deleted` (`is_deleted`),
  CONSTRAINT `fk_note_item_user` FOREIGN KEY (`user_id`) REFERENCES `t_user` (`id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='笔记表';
```

#### 3.1.4 登录失败记录表 (t_login_fail_record)
```sql
CREATE TABLE `t_login_fail_record` (
  `id` BIGINT NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `username` VARCHAR(50) NOT NULL COMMENT '用户名',
  `ip_address` VARCHAR(50) NOT NULL COMMENT 'IP地址',
  `fail_count` INT NOT NULL DEFAULT 1 COMMENT '失败次数',
  `lock_until` DATETIME DEFAULT NULL COMMENT '锁定到期时间',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_username_ip` (`username`, `ip_address`),
  KEY `idx_lock_until` (`lock_until`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='登录失败记录表';
```

#### 3.1.5 敏感词表 (t_sensitive_word)
```sql
CREATE TABLE `t_sensitive_word` (
  `id` BIGINT NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `word` VARCHAR(100) NOT NULL COMMENT '敏感词',
  `type` TINYINT NOT NULL COMMENT '类型: 1-政治, 2-色情, 3-暴力, 4-广告',
  `status` TINYINT NOT NULL DEFAULT 1 COMMENT '状态: 1-启用, 0-禁用',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  PRIMARY KEY (`id`),
  KEY `idx_word` (`word`),
  KEY `idx_type_status` (`type`, `status`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='敏感词表';
```

### 3.2 索引优化说明
- **t_user**: username、email 唯一索引，last_active_at 普通索引(排序用)
- **t_main_link**: user_id 唯一索引，updated_at 普通索引(排序用)
- **t_note_item**: (user_id, updated_at) 联合索引(用户笔记列表查询优化)，user_id 单独索引，updated_at 单独索引(全局排序用)
- **t_login_fail_record**: (username, ip_address) 唯一索引，lock_until 普通索引(定时清理锁定记录)

## 五、核心业务逻辑设计

### 5.1 登录安全机制
1. **登录失败计数**: 使用Redis存储用户名+IP的失败次数
2. **锁定机制**: 失败5次后锁定10分钟
3. **密码加密**: 使用BCrypt加密存储
4. **Token管理**: JWT Token，有效期7天

### 5.2 敏感词过滤
1. **DFA算法**: 使用DFA(确定性有限自动机)实现高效敏感词检测
2. **缓存优化**: 敏感词列表缓存到Redis，定期刷新
3. **拦截策略**: 检测到敏感词时拒绝提交并提示

### 5.3 权限控制
1. **数据隔离**: 用户只能操作自己的数据
2. **访客权限**: 未登录用户只能查看，不能修改
3. **Token验证**: 所有写操作需要验证Token

### 5.4 性能优化
1. **缓存策略**: 热点用户数据缓存到Redis
2. **分页查询**: 所有列表接口支持分页
3. **索引优化**: 数据库索引覆盖常用查询场景

### 6.2 统一异常处理
```java
@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(BusinessException.class)
    public Result<?> handleBusinessException(BusinessException e) {
        return Result.error(e.getCode(), e.getMessage());
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public Result<?> handleValidationException(MethodArgumentNotValidException e) {
        String message = e.getBindingResult().getAllErrors().get(0).getDefaultMessage();
        return Result.error(ErrorCode.BAD_REQUEST.getCode(), message);
    }

    @ExceptionHandler(Exception.class)
    public Result<?> handleException(Exception e) {
        log.error("系统异常", e);
        return Result.error(ErrorCode.INTERNAL_ERROR);
    }
}
```
