# 登录页邮箱验证码重置密码设计

## 目标

为未登录用户提供“忘记密码”入口，通过账户绑定邮箱获取一次性验证码并设置新密码。功能沿用当前 Vue 3、Element Plus、Spring Boot、Redis、邮件服务及 BCrypt 实现，不改动数据库结构，也不改变已登录用户的修改密码流程。

## 用户流程

1. 用户在登录页点击“忘记密码？”，进入公开路由 `/forgot-password`。
2. 用户输入邮箱并请求验证码。
3. 前端调用 `POST /api/user/auth/send-code`，请求场景固定为 `resetPassword`。
4. 后端仅为已注册邮箱生成并发送验证码；无论邮箱是否注册，发送接口均返回通用成功提示，避免泄露账户是否存在。
5. 用户填写 6 位验证码、新密码和确认密码，提交至 `POST /api/user/auth/reset-password`。
6. 后端校验验证码并按邮箱定位账户，以 BCrypt 保存新密码。
7. 重置成功后使该用户之前签发的 JWT 失效，清除登录失败次数；普通登录锁定状态恢复为正常，管理员禁用状态保持不变。
8. 前端跳回登录页并提示用户使用新密码登录。

## 前端设计

### 登录页

在密码输入区域附近增加右对齐的“忘记密码？”链接，不改变原有登录和注册链接。

### 忘记密码页

新增 `ForgotPassword.vue`，视觉结构复用登录和注册页：

- 邮箱输入框；
- 6 位验证码输入框及“获取验证码”按钮；
- 成功发送后的 60 秒倒计时；
- 新密码输入框；
- 确认新密码输入框；
- “重置密码”主按钮；
- “返回登录”链接。

客户端校验：

- 邮箱不能为空且格式合法；
- 验证码必须为 6 位数字；
- 新密码长度为 6–100 位；
- 两次密码必须一致；
- 请求进行中禁用相应按钮，防止重复发送和重复提交；
- 页面卸载时清理倒计时定时器。

新增公开路由 `/forgot-password`、`ResetPasswordRequest` 类型和 `resetPassword()` API 封装。

## 后端设计

新增 `ResetPasswordDTO`：

- `email`：必填、邮箱格式；
- `verificationCode`：必填、6 位数字；
- `newPassword`：必填、长度 6–100 位。

在 `AuthController` 增加公开接口：

```text
POST /user/auth/reset-password
```

在认证服务中实现：

1. 规范化输入的首尾空白；
2. 校验 `resetPassword` 场景验证码并一次性消费；
3. 按邮箱查找用户；
4. 使用现有 BCrypt 参数加密新密码；
5. 更新密码及更新时间；
6. 若账户状态为普通登录锁定状态 `2`，恢复为正常状态 `1`；状态 `0` 的管理员禁用账号不解禁；
7. 写入现有 `user:token:invalid_before:<userId>` 标记，使旧 JWT 失效；
8. 清理该用户现有登录失败计数。

现有发送验证码接口只接受 `register`、`changePassword` 和 `resetPassword` 三个场景，防止客户端通过构造任意场景绕过 Redis 的发送间隔及每日限额。`resetPassword` 场景仅向已注册邮箱发送，但对不存在的邮箱返回相同的通用结果。

## 安全与异常处理

- 验证码继续采用现有 6 位安全随机数、5 分钟有效期、60 秒发送间隔和每日 10 次上限。
- 验证码与注册、已登录改密场景隔离，并在验证成功后立即删除。
- 密码只保存 BCrypt 哈希，不记录或返回明文。
- 不复用依赖 JWT 的 `/user/users/password` 接口，避免身份对象混淆。
- 发送阶段使用通用提示隐藏邮箱注册状态。
- 验证码错误、失效、发送频繁、达到每日上限及参数校验错误继续使用项目统一 `BusinessException` / `Result` 响应。
- 前端沿用 Axios 拦截器和 Element Plus 消息提示。

## 数据与兼容性

`t_user.email` 已有唯一索引，用户实体已有密码、邮箱、状态和更新时间字段，因此无需数据库迁移。现有注册、登录和已登录改密接口行为保持不变。

## 验证范围

实现后进行与本功能直接相关的验证：

1. 后端 Maven 编译；
2. 用户端 TypeScript 类型检查；
3. 用户端生产构建；
4. 验证已注册邮箱发送验证码、错误验证码、过期验证码、两次密码不一致及重置成功路径；
5. 验证旧密码失效、新密码可登录、旧 JWT 失效；
6. 验证不存在邮箱不泄露账户状态；
7. 验证禁用账号不会因重置密码被解禁。
