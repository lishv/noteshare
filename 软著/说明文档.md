## 一、系统概述

### 1.1 编写目的

本说明书用于介绍笔记共享平台的组成、运行环境、主要功能和具体操作流程，为软件使用者、系统维护人员及软件著作权登记审核人员提供使用依据。说明书按照管理端和用户端两个部分组织，所有功能说明均以当前系统实际页面和操作流程为准。

### 1.2 系统简介

笔记共享平台是一套面向知识记录与内容分享的 Web 应用系统。系统支持用户注册、登录、Markdown 笔记创作、外链笔记收集、公开或私密保存、内容搜索、作者关注、点赞、收藏、评论、通知和分享等功能；同时提供管理端，用于维护用户、笔记、评论、站内消息、链接、敏感词、统计数据和管理员信息。

系统采用前后端分离的 B/S 架构。用户通过浏览器访问用户端页面，管理员通过管理端页面进行平台运维。前端负责页面展示、交互和表单校验，后端负责身份认证、业务处理、权限校验、数据分页及持久化。用户只能操作本人有权限的数据，管理员在通过管理端认证后可以按照管理权限查看和维护平台数据。

### 1.3 系统组成

系统由以下部分组成：

1. 用户端 Web 系统：为普通用户提供笔记浏览、创作、分享及社交互动功能。
2. 管理端 Web 系统：为管理员提供平台内容、用户和运行数据管理功能。
3. 后端服务：提供认证、笔记、评论、关注、通知、统计及管理接口。
4. 数据存储：保存用户、笔记、标签、互动记录、通知、操作日志等业务数据，并通过软删除等机制保留必要的管理记录。

### 1.4 用户角色

系统包含普通用户、管理员和超级管理员三类使用角色。普通用户可以管理本人资料和笔记，并浏览公开内容及参与互动；管理员可以执行平台日常管理操作；超级管理员在管理员权限基础上可以进入管理员管理模块，维护其他管理员账号。

### 1.5 运行环境与访问方式

用户端和管理端均可在安装现代浏览器的计算机上运行，建议使用 Chrome、Microsoft Edge 等 Chromium 内核浏览器，并将浏览器窗口设置为不低于 1280×720 的分辨率。服务端运行环境包括 Java 17、Spring Boot 3.2、MySQL 和 Redis，前端项目使用 Vue 3、TypeScript 和 Vite 构建。

系统实际访问地址由部署环境配置确定。用户端和管理端分别使用各自的 Web 地址访问，登录成功后由系统保存认证令牌并根据用户角色控制可访问页面。用户端未登录访问受保护页面时，系统会跳转至登录页面；管理员未通过管理端认证时不能访问后台业务页面。

## 四、系统使用注意事项

### 4.1 账号与权限

用户应妥善保管账号、密码和邮箱验证码，不要在公共设备上长期保存登录状态。普通用户只能查看公开内容以及本人有权访问的私密内容，不能访问其他用户的私密笔记，也不能操作其他用户的通知、笔记或评论。管理员应按照实际职责使用管理功能，超级管理员应谨慎维护管理员账号。

### 4.2 内容发布

发布笔记前应确认标题、正文、标签和可见性设置正确。外链笔记应填写可访问的 HTTP 或 HTTPS 地址，不应填写脚本协议或其他危险协议。系统对笔记、评论和资料内容执行敏感词检查，出现提示时应根据提示修改内容后重新提交。

### 4.3 删除与恢复

用户删除笔记、管理员删除评论或管理员移除通知时，系统优先采用软删除方式。软删除数据在普通列表中不再展示，但仍可在相应回收站或管理页面中查询、恢复或进一步销毁。执行彻底删除或清空回收站前，应确认所选记录不再需要保留。

### 4.4 分页与数据刷新

列表页面按页加载数据。执行搜索、筛选、删除、恢复、点赞、取消点赞或取消收藏后，系统会重新计算当前列表；当当前页没有记录时，页面会自动回到合理的上一页。若浏览器网络暂时中断，用户应等待提示完成后再重试，避免重复提交。

### 4.5 浏览器与网络

建议使用最新版本的 Chrome 或 Microsoft Edge，并允许页面使用必要的本地存储、图片上传和新标签页功能。分享海报和外链访问依赖浏览器的弹窗及网络策略，若浏览器阻止新标签页，应在地址栏提示中允许当前站点打开新窗口。

## 五、常见操作结果

1. 登录成功：进入用户端首页或管理端仪表盘，并显示当前账号信息。
2. 登录失败：当前页面提示账号、密码或账号状态异常，用户可以修正后重新提交。
3. 发布成功：笔记出现在本人笔记列表，并根据公开状态进入相应的公共或私密区域。
4. 点赞或收藏成功：按钮状态和对应数量立即更新，刷新页面后状态仍保持一致。
5. 通知移除成功：该通知从用户端当前列表中消失，管理员仍可在已移除状态中查询。
6. 评论删除或恢复成功：管理端列表更新状态，并在操作日志中留下管理记录。
7. 图片或文件校验失败：页面提示文件类型或大小不符合要求，用户更换文件后可以再次上传。
8. 权限不足：系统拒绝当前操作并提示用户返回具有权限的页面或重新登录。
